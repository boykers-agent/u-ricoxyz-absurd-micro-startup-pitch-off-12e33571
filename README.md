One-sentence pitch for an absurdly specific micro-startup, written for the make.fun bounty.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
We sell artisanal error messages for startups — handcrafted 500s so your users feel personally disappointed instead of merely confused.
```
